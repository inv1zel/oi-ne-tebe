# ой. это вообще не тебе.

Маленький интерактивный «тест на милоту», который на самом деле совсем не тест.
React + Vite, без сервера, без аналитики и без звука. Всё работает прямо в браузере.

## Запуск локально

Нужен Node.js 18+.

```bash
npm install
npm run dev        # http://localhost:5173
```

Production-сборка и её предпросмотр:

```bash
npm run build      # результат в папке dist/
npm run preview    # http://localhost:4173
```

## Как опубликовать бесплатно

Сборка использует относительные пути (`base: './'`), поэтому `dist/` работает на любом хостинге.

**Самый простой способ: Netlify Drop (без аккаунта на GitHub)**
1. `npm run build`
2. Откройте https://app.netlify.com/drop
3. Перетащите туда папку `dist`. Через пару секунд появится ссылка вида `https://что-то.netlify.app`.
4. В настройках сайта (Site configuration → Change site name) можно задать имя, например `oi-ne-tebe.netlify.app`.

**Vercel**
1. Загрузите проект в репозиторий на GitHub.
2. На https://vercel.com нажмите New Project и выберите репозиторий. Vite определится сам
   (Build: `npm run build`, Output: `dist`).

**GitHub Pages (уже настроено)**
1. В репозитории откройте Settings → Pages и в поле Source выберите **GitHub Actions**.
2. Каждый пуш в `main` сам собирает и публикует сайт (`.github/workflows/deploy.yml`).
3. Ссылка будет вида `https://<логин>.github.io/<репозиторий>/`.

Сайт помечен `noindex`, поэтому поисковики не будут его показывать: ссылку увидит только тот, кому вы её отправите.

## Где что лежит

```
src/
  App.jsx                    — экраны и переходы (loading → welcome → quiz → analysis → results → finale)
  data/content.js            — ВСЕ тексты: вопросы, реакции, шепотки, строки анализа и финала
  fx/                        — общие эффекты: частицы-сердечки, конфетти, уведомления
  hooks/                     — таймеры с автоочисткой, prefers-reduced-motion
  components/
    Loader.jsx               — загрузка (~1 с, только при первом открытии)
    Header.jsx, Whisper.jsx  — название сайта (секрет) и случайные подписи в углу
    Welcome.jsx              — главный экран
    quiz/                    — тест: прогресс, карточка вопроса, попап, стикеры
    Analysis.jsx             — «анализ ответов»
    Results.jsx              — результаты
    Certificate.jsx          — сертификат (окно, печать)
    Finale.jsx               — неожиданный финал
    decor/                   — фон, плавающие сердечки, звёздочки, сердечко с лицом
    ui/                      — кнопки
```

Чтобы поменять любой текст, достаточно отредактировать `src/data/content.js`
(финальную карточку — в `src/components/Finale.jsx`).

## Секреты

- Нажмите на большое сердечко или на маленькие сердечки: они лопаются. После 5 нажатий на большое сердечко будет отдельная реакция.
- Три быстрых нажатия на название сайта вверху открывают секретное сообщение.
- В углу время от времени появляются подписи.
- Кнопка «пройти ещё раз» сбрасывает прогресс.
